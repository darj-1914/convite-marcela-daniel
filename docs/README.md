# Convite Digital - Daniel e Marcela

Projeto estatico de pagina unica, preparado para publicar no GitHub Pages pela pasta `docs/`.

## Onde editar

Edite apenas `docs/js/config.js`.

Nele voce consegue alterar:

- nomes dos noivos
- data
- horario
- local
- links da lista de presentes e confirmacao de presenca
- textos curtos
- cores
- imagem do monograma
- imagem do Pier 31
- imagem do casal
- texto da carta inicial

## Onde trocar imagens

Arquivos atuais:

- `docs/assets/images/monograma.png`
- `docs/assets/images/pier31.png`
- `docs/assets/images/casal.png`

Voce pode:

1. Substituir o arquivo mantendo o mesmo nome.
2. Ou colocar um novo arquivo em `docs/assets/images/` e ajustar o caminho em `docs/js/config.js`.

## Publicacao no GitHub Pages

1. Crie um repositorio no GitHub.
2. Envie todo o conteudo do projeto.
3. No GitHub, abra `Settings > Pages`.
4. Em `Build and deployment`, selecione `Deploy from a branch`.
5. Escolha a branch principal e a pasta `/docs`.
6. Salve e aguarde a geracao do link publico.

## Imagens recomendadas

### Imagem do Pier 31

- formato: `webp` ou `jpg`
- orientacao: horizontal ou panoramica suave
- largura recomendada: `1600px` ou mais
- enquadramento: preservar a arvore central e a passarela

### Monograma

- formato: `png` ou `svg` com fundo transparente
- area recomendada: quadrada
- tamanho recomendado: `800x800`

### Arte do casal

- formato: `png`, `webp` ou `svg` com fundo transparente
- orientacao: vertical
- tamanho recomendado: `900x1200`
